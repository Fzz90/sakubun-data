# スマホで一番よく使う機能（作文調査発表）

第A組による大学生6名のスマホ利用実態調査プレゼンテーション（数学テーマ・全5スライド・日本語版）。

- **公開URL**: https://fzz90.github.io/sakubun-data/

## 主な機能
- アニメーション付きインタラクティブ円グラフ（項目クリックで回答者の内訳を表示、再生ボタン付き）
- ふりがな表示／非表示切り替え
- キーボード操作（`←` / `→` / `Space` / `Home` / `End` / `F`）およびモバイルスワイプ対応
- レスポンシブ設計（デスクトップ 16:9・タブレット・スマートフォン・印刷／PDF出力対応）
